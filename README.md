# Resumes

This repository contains my personal resume source files, built with [`markdown-resume`](https://github.com/junian/markdown-resume) and [`rendercv`](https://github.com/rendercv/rendercv). If you want to see how they look, you can use their respective online editors ([`markdown-resume`](https://www.junian.dev/markdown-resume) and [`rendercv`](https://rendercv.com)) to preview them.

If you are interested in my previous polished LaTeX template, you can find it in this [repository](https://github.com/braz9LKDI/LaTex_resume).

I chose these tools because I plan to maintain different resumes for different roles, and I want the workflow to stay as simple as possible. LaTeX is powerful, but its compilation artifacts can get noisy quickly, especially when managing multiple resume versions.
